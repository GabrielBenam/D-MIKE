# ESTADO — Proyecto D-MIKE (motor principal)

D-MIKE es el nombre del software (por la mnemotecnia DMAIC). Actualizado: 13/10/2026. Súbelo al inicio de cada sesión nueva y pide que lo actualice al cerrar.

## Objetivo
Programa de escritorio para Windows, sin conexión, con módulos independientes al estilo Minitab y un modo Proyecto por fases DMAIC. Formatos propios, exporta .xlsx y .csv planos para Minitab y pide datos según el avance. Primer usuario real: caso JANA (se lleva en otro proyecto; sus datos no entran aquí).
